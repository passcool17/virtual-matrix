# Virtual Matrix · Lockdown Implementation Plan

> **For agentic workers:** executed inline (executing-plans) by the Arcade executor. Steps use checkboxes (`- [ ]`). Progress log: `/workspace/games/virtual-matrix/PROGRESS.md`.

**Goal:** a static recreation of Virtual Matrix + 6 locks (ACCESS DENIED/GRANTED), firewall alert, sentinel, timed score.
**Architecture:** one ES module per responsibility; a single mutable state `G` (main.js) shared through imports; the locks are DOM objects (pure logic + rendering) driven by `G.t`; three.js only for the 3D world.
**Tech Stack:** three.js r170 vendored, vanilla JS ES2022, CSS, WebAudio, Playwright (tests, outside the repo).

## Global Constraints
- No build step, no npm dependency in the game. Relative paths (Pages under /virtual-matrix/).
- FR text, original sentences, fictional content.
- `event.code` for keys. `?qa=1` = immediate jack in. `window.__vm` = test hooks.
- Game time `G.t` (dt ≤ 0.1). Tests wait on `G.t`, never fixed sleeps for game logic.
- CONFIG: wrap 36, yMin 1.2, yMax 42, flySpeed 14, boostMul 2.05, lookSens 0.0022, hackRange 3.6.
- localStorage: `vm-lockdown-best` = `{t,denied}`.

## Shared interfaces
- `config.js`: `CFG`, `COL`, `NODES[{id,title,x,y,z,phrase}]`, `ALERT{perDeny:1,perGrant:2,decay:1/15,max:8}`, `alertLevel(a)`.
- `audio.js`: `initAudio()`, `setMuted(b)`, `sfx.{jack,decode,deny,complete,key,tick,granted}()`.
- `rain2d.js`: `startRain(canvas, density) → stop()`.
- `input.js`: `bindInput(el)`, `readInput() → {moveX,moveY,rise,boost,lookX,lookY,hack,pause,mute}`, `onKey(fn)` (raw keydown to the open lock), `isTouch()`, `setRise(v)`, `setJoy(x,y)`, `pressHack()`, `requestLock()`, `releaseLock()`.
- `world.js`: `createWorld(canvas) → {render(G), resize(), setNodeState(id,state), sentinel:{show,hide,pos}, clues:[{id,pos}], fps}`.
- `locks.js`: `makeLock(id, ctx) → {id, el, key(code,key), update(t), solution(), autoSolve()}`; ctx = `{G, clue(id), fragments(), deny(msg), grant(), sfx}`.
- `ui.js`: screens (`showScreen(name)`), HUD refresh, `denyLine()`, `grantBurst(title)`, `banner(text)`, `toast(text)`, radar.
- `main.js`: `G`, phases `boot|blue|playing|paused|complete`, loop, alert, sentinel, score, `window.__vm`.
